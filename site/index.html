// méthode de travail

Comment je travaille

git init contact

01. Premier échange

On discute de votre besoin réel : objectif du site, public visé, contraintes techniques et budget. Cette étape cadre tout le reste.

git checkout -b design

02. Conception & Design

Je propose une direction visuelle et une structure de page avant d'écrire la moindre ligne de code, pour valider ensemble l'expérience utilisateur.

git commit -m "feat: build"

03. Développement

Le design devient du code : front, back, base de données. Vous suivez l'avancement et on ajuste au fil de l'eau.

git merge --deploy

04. Tests & Mise en ligne

Tests sur mobile et desktop, corrections finales, puis mise en ligne. Je reste disponible après la livraison pour les ajustements.
